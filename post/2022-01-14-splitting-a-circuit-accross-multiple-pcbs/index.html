Tech Tidbit: Splitting circuits into multiple PCBs in KiCAD

Fri, Jan 14, 2022
Draft tips

A couple of weeks ago, I talked about mousebiites–a way to print multiple PCBs in a single panel. It wasn’t very cost effective if you had multiple designs.

Because of this, I was curious about the experience if I had printed the PCBs of my modules in individuals instead of having them in a single panel. For this article, I’ll use my recent MiniMult project as an example. It has two boards: the front panel and the main board.

How do I prepare the files?

For KiCAD, it was pretty simple. I copied the .kicad_pcb files two times–one for each board. I then opened each PCB file on Pcbnew, KiCAD’s standalone PCB layout viewer, and deleted components outside of each board.

I then plotted my files as you would usually do, zipped them up by board, then submitted each one to PCBWay for fabriction.

Was it better than mousebites?

It’s cheaper than mousebites and the edges are cleaner. I didn’t need to fill off anything.

Maybe I’ll stick with it.
