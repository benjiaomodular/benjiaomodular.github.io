Tech Tidbit: Overvoltage Protection

Fri, Jan 28, 2022
Draft tips

I cannot recall the number of Arduino Nano’s I’ve had to throw away after plugging in 12 volts into the 5 volt-rated input pins.

My testing setup

My testing setup involves my Baby 8 sequencer module, with no clock – therefore producing a static voltage. Because it uses a 9V power supply it’s output ranges from 0-9V. Perfect for testing.

I used an AS78L05 voltage regulator to produce a 5V reference whenever a 5V reference voltage was needed. This was set up using the sample circuit from its datasheet.

My Options

Clamping diodes

I’ve learned this method from HAGIWO’s blog, where he usually clamps the inputs of is Arduino projects using two diodes and a resistor. I’ve been doing this for a while but only recently have I decided to check how effective it is using a scope.

The input voltage seemed to be unaffected by the circuit accross the expected usable range. However, I found it strange that the circuit only limited my output at 6.2V.

1N4733 Zener Diode

The 1N4733 is a Zener Diode with a reverse breakdown voltage of 5.1V. Which is roughly what we need.

TL7726 IC

I have read about these in a Reddit post and decided to try it out. It seemed to make sense for Arduino projects that contain multiple CV and audio inputs. In those cases, I could take advantage of the six clamps this circuit provides.
